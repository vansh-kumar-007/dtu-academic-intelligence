# DTU Academic Intelligence Platform

An AI-powered platform built around DTU's examination ecosystem.

## Features (Planned)
- Automated result scraping and monitoring
- Search across results, sessions, semesters, branches
- Analytics dashboard with historical trends
- AI prediction of result declaration dates
- Email and Telegram notifications
- RAG-based AI assistant for student queries
- Public API access

## Tech Stack
- **Backend:** FastAPI (Python)
- **Frontend:** Next.js
- **Database:** PostgreSQL
- **Vector DB:** Qdrant
- **AI Layer:** LangChain / LangGraph
- **Scraping:** BeautifulSoup / Requests
